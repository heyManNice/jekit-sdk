# 见客，不识客。

Jekit 品牌宣传片，35 秒。纯静态页面：WebGL2 渲染画面，Web Audio 实时合成配乐，没有构建步骤，也不依赖任何库。

用浏览器直接打开 `index.html`，点击播放（建议戴耳机、按 `F` 全屏）。

功能讲解片在 `apps/explainer`，那是基于 Remotion 的另一个工程。

## 分镜

120 BPM，所有切换落在节拍上。

| 时间 | 段落 | 画面 | 声音 |
| --- | --- | --- | --- |
| 0–4s | 序 | 一粒光点随心跳亮起。「每一次访问」 | 心跳、阴暗的铺底 |
| 4–10s | 负担 | URL、Cookie、IP 等 14 种数据碎片吸附上来，光点变暗、发抖、出现故障。「都在被记住」 | 心跳加速，噪声与不和谐音升起 |
| 10–12s | 静默 | 画面冻结、褪色。「如果，只记住你来过呢？」 | **完全无声**，第二行字出现时落下一声钟 |
| 12–18s | 剥离 | 光点穿过四层光膜，碎片逐层剥落。剩下 **10 字节**，这是一次真实请求体的十六进制。「无 Cookie / 无访客 ID / 无设备指纹 / 无 URL」 | 冲击音、鼓点、十个音的上行音阶 |
| 18–24s | 汇聚 | 光点汇入光河，光河变成一条趋势曲线，再分出 8 条来源支流，其中 AI 渠道为紫色 | 四拍底鼓、拍手、十六分音符琶音 |
| 24–28s | 简单 | `npm i jekit-react`，「一条命令 · 无需注册 · 完全免费 · 开源透明」 | 按键声、每拍一声钟 |
| 28–35s | 落版 | 全场粒子聚成 Logo。「见客，不识客。」jekit.cn | 冲击音，混响尾音中最后一次心跳 |

第 2 段的 10 个字节按 `packages/core` 的 `/greet` schema 编码：一位新访客从 ChatGPT 进入 `/blogs/20260802-2006/`，使用 Windows 上的 Chrome，TTFB 118ms，PLT 476ms。

## 控制

| 按键 | 作用 |
| --- | --- |
| 空格 / 点击画面 | 播放 / 暂停 |
| ← → | 后退 / 前进 2 秒 |
| Shift + ← → | 跳到上一段 / 下一段 |
| 0 – 6 | 跳到第 N 段 |
| , . | 逐帧 |
| F | 全屏 |
| H | 隐藏控制条 |
| R | 从头录制一遍，导出 `jekit-promo.webm`（含声音） |

URL 参数：`?t=12` 从第 12 秒开始；`?autoplay` 自动播放（浏览器可能要求先点击）；`?mute` 静音预览；`?debug` 显示帧率和粒子数。

## 文件

```text
index.html     页面、样式、控制条
js/util.js     缓动、关键帧、随机数等纯函数
js/score.js    总谱：画面和声音共用的唯一时间表
js/audio.js    配乐合成与排程
js/gl.js       WebGL2 管线：背景着色器、实例化粒子、泛光、合成
js/film.js     分镜：给定时间 t，算出这一帧的粒子、文字和后期参数
js/main.js     时钟、渲染循环、键盘控制、录制
js/logo.js     内嵌的 Jekit 字标（data URL）
```

## 实现要点

- **画面是时间的纯函数**：同一个 t 永远得到同一帧，不在帧之间累积状态。因此可以任意跳转，掉帧也不会让音画错位。
- **音画共用一个时钟**：所有声音在播放开始时一次性排好，画面读取 `AudioContext.currentTime`。
- **改节奏只改 `score.js`**：心跳、碎片出现、冲击点、鼓点、字幕切换的时间都在这里。
- **字体**：中文依次回退到 PingFang SC、HarmonyOS Sans SC、微软雅黑。不同系统上字形略有差异，但不影响版式。
- **录制**：用 `MediaRecorder` 实时录制，导出 webm。要转成 mp4 可以用 `ffmpeg -i jekit-promo.webm -c:v libx264 -crf 18 -c:a aac jekit-promo.mp4`。录制期间请保持标签页在前台。
