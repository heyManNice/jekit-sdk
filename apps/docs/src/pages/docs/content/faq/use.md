## 统计面板显示该网站无记录，请稍后重试

- 这个响应表示你查询的网站没有在服务器中登记。安装 Jekit 之后至少访问一次你的网站来进行登记。
- 可能是 Jekit 的当日网站新增数量达到上限，需要等下一天恢复。也可以加入官方交流群询问具体原因。
- Jekit 的每日新增数量没有具体值，按照网站流量调整。目的是防止服务器资源被无限耗尽。

## 统计面板要求同时输入域名和路径来查询，使用比较麻烦

- 一个更方便的产品设计应该是你只需要输入域名，统计面板能自动展示每一个路径的指标。
- 但因为极致的隐私安全设计，我们无法实现此功能，路径中可能包含用户的隐私信息。
- 因此，前端根本不会上传路径信息，即服务器的后端并不知道你的域名下有哪些子页面。
- 如果你追求方便，可以通过 [API 开放平台](/docs/more/api/) 自己搭建专属面板，自动查询自己知道的路径信息。

## 如何查询页面标识里带查询参数或 hash 的页面

- 直接在搜索框粘贴完整 URL 即可，查询参数与 hash 会一并纳入页面标识（规则见 [Jekit 如何区分不同的页面](/docs/faq/impl/)）。
- 例如 `/article?id=1` 和 `/article?id=2` 是两个页面，需要分别查询。
- 追踪类参数（`?utm_source=`、`?from=` 等）会被自动忽略，所以粘贴带推广参数的分享链接同样能命中同一个页面。
- 也可以使用 [API 开放平台](/docs/more/api/)，在 `path` 里传入包含查询参数或 hash 的完整路径。
