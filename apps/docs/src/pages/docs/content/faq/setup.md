## 安装完成之后，页面上统计的数值显示 Err
- 通常是本地环境禁用 Jekit Greet，部署到线上后即可。你可以进入浏览器控制台查看具体的错误原因。
- 也可能是达到了网站的每日新增数量上限，点击 [使用问题](../use/) 查看更多信息

## 新页面无法正确统计，页面访问量始终为 0
- 这种情况通常发生在网站子页面数达到 50 个时，服务器会拒绝统计新的页面。目的是防止服务器资源被无限耗尽。
- 50 个的取值权衡了大部分的情况。如果你有更多需求可以在安全校验通过后免费提高该限制。
- 后续可能会有某种自动化校验方案，目前为人工校验，请添加交流群进一步交流。
- 你可以在 [统计](/stats/) 页面中查看你的域名的子页面限制值。
