## CDN 导入会拖慢我的网站加载速度吗？
- 不会。Jekit CDN 采用异步加载方式，不会阻塞网站原本的服务，并且 Jekit 会尽可能的提供响应最快的脚本资源。

## Jekit 支持 SPA 的虚拟路由吗？
- 支持。所有的 Jekit 封装都支持 SPA 应用。虚拟路由变化时能触发统计，但不会记录性能。

## Jekit 的隐私安全做到什么程度？
- 这是 Jekit 最值得骄傲的一个特色之一，Jekit 的隐私安全设计超乎想象。
- Jekit 不会上传 Referrer、Path、Query、Title、Cookie。后端不处理 UserAgent (但浏览器强制上传)。
- Jekit 不生成用户ID，不生成设备指纹、不追踪用户，不记录IP、地域和语言、不记录用户操作。
- 你可能会很疑惑 Jekit 在这种条件下如何实现现有功能，请查看技术博客详细说明。
