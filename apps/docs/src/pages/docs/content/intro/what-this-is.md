## 介绍
Jekit 是一个公益性质的免费公共统计基础工具，中文名为见客统计，域名为 jekit.cn。  
Jekit 的首要目标是打造一个**隐私安全**、**简单易用**的公共统计工具。更多疑问请阅读 [答疑解惑](/docs/faq/setup/) 部分。  
如果您的身份是个人站长、开源网站等，Jekit 正是为您准备的。  
欢迎加入 技术交流 QQ 群：1048301483

**以下是 Jekit 的主要特色：**
- **无需注册**，引入代码即可享受对应功能
- **免费使用**，只要没关服可永久免费使用
- **数据公开**，所有记录任何人都可以查询
- **开源透明**，SDK 代码接受查阅和改进
- **隐私合规**，不采用任何追踪用户手段
- **安装简单**，自带多种现代框架封装
- **数据安全**，官方每天异地冷备数据库
- **指标丰富**，记录多种站长感兴趣的指标
- **历史指标**，无限期记录和查询各种指标
- **开放接口**，可自行定制统计数据大屏

## 代码风格预览（以 Vue 为示例）
```vue
<script setup lang="ts">
import { useJekit } from 'jekit-vue';
const jekit = useJekit();
</script>

<template>
	<p>网站总访问量: {{ jekit.sitePv }} 次</p>
	<p>网站总访客数: {{ jekit.siteUv }} 人</p>
	<p>页面总访问量: {{ jekit.pagePv }} 次</p>
	<p>页面总访客数: {{ jekit.pageUv }} 人</p>
	<p>今日网站总访问量: {{ jekit.sitePvToday }} 次</p>
	<p>今日网站总访客数: {{ jekit.siteUvToday }} 人</p>
	<p>今日页面总访问量: {{ jekit.pagePvToday }} 次</p>
	<p>今日页面总访客数: {{ jekit.pageUvToday }} 人</p>
</template>
```

## 使用场景

**如果您有以下的任意一点需求，非常推荐您使用 Jekit**
- 站长希望自己的统计信息是公开透明的
- 站长希望统计工具是轻量并且隐私安全的
- 在网站页脚展示当前网站的访客数或请求数量
- 在文章标题下展示该文章的阅读量
- 站长需要查看网站的基础流量指标
- 站长需要查看网站的性能指标
- 站长需要查看网站的搜索引擎来源(包含AI途径)
- 站长需要查看网站的浏览器种类来源
- 站长需要查看网站的操作系统种类来源
- 站长需要查看以上所有指标的历史信息
